# 厚外与上海交大拟合作项目共选台

[打开在线页面](https://xiaoxiao430.github.io/sjtu-houde-projects/)

用于讨论和选择教育教学、教学管理与校园支持项目。内容为拟合作构想，尚待双方确认团队、实施范围、经费与成果安排。

## 怎样使用

1. 先看教育教学与教学管理重点，展开具体项目，查看案例、软件、硬件、使用角色和推荐理由。
2. 点击“加入本次合作”。讯飞、希沃等成熟产品使用“加入产品参考”，供比较与设备适配讨论。
3. 右侧项目清单可移除、上移、下移、填写项目意见与实施顺序；手机端点击“本次交大合作”打开清单。
4. 填写文档名称与本次合作重点，点击“生成合作清单 Word”，下载可编辑的 A4 DOCX。文档包含所选项目、软硬件路线、具体做法、预期好处、推荐理由、备注与待确认事项。

重点涵盖教师备课与 AI 课件、课堂 Agent、智慧作业、巡课与听评课、大教研、班级 Agent、教学运行，以及校园安全传感与处置、校园餐追溯和健康支持。原8类51项清单、综合合作构想及厂商产品参考继续保留。

## 选择怎样保存

- 每个人的选择与意见保存在自己的浏览器，不提交到 GitHub，也不会覆盖其他人的选择。
- “待了解”和“暂不考虑”保留在本地备份中，不进入本次合作 Word。
- 可导出 JSON 备份，在其他浏览器导入，或将 Word 发给参与讨论的人。
- 旧版本地 HTML 与在线页面属于不同浏览器来源，原有选择不能自动跨来源读取。请先从旧版导出备份，再在新版导入；支持原格式备份。
- 清理浏览器存储可能删除本地选择，重要讨论前请下载备份。

## 页面与资料说明

页面为离线可运行的单文件 HTML，不依赖 CDN、付费接口或服务器。下载 `index.html` 后也可在浏览器打开；Word 在浏览器本地生成。全页使用微软雅黑；DOCX 所有文本均指定 Microsoft YaHei。

AI 课件以厚外正在推进的相关工作作为研发基础，具体已实现功能与接口仍需盘点。国家平台、教材、第三方资料按各自许可条件使用，由教师审校后采用。

安全设备和既有安全平台负责实时报警与规定的联动；Agent 辅助关联记录、通知与跟进，不代替现场处置。校园餐、营养与健康资料按岗位分工使用，专业判断由相应人员负责。

产品能力来自厂商公开介绍，接口、费用和厚外场景效果尚需逐项验证；加入产品参考不代表采购。公开活动图片、产品图附原始出处，AI 构想图与流程示意均作标注，不代表厚外已开展的活动或真实运行数据。
